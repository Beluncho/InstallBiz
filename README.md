# 📁 Анализатор файлов

Сервис для скачивания и анализа текстовых файлов через внешнее API.

## 📋 Описание

Сервис позволяет:
- Скачивать файлы через API с ограничениями (до 3 файлов за запрос)
- Отслеживать прогресс скачивания в реальном времени
- Анализировать содержимое файлов (500 цифр от 0 до 9)
- Отображать статистику по каждому файлу и общую статистику

## ⚙️ Установка

### 1. Клонировать репозиторий
```bash
git clone git@github.com:Beluncho/InstallBiz.git
git clone https://github.com/Beluncho/InstallBiz.git
```
### 2. Установить зависимости
```bash
pip install -r requirements.txt
```
### 3. Настроить конфигурацию
В файле main.py укажите:

```python
API_BASE_URL = "http://91.199.149.128:18001"  # URL внешнего API
CANDIDATE_ID = "beluncho.github.io"  # Ваш ID (или None)
```
### 4. Запустить сервис
```bash
python main.py
```
### 5. Открыть в браузере
```text
http://localhost:8000
```
# 🚀 Использование
## Скачивание файлов
1. Нажмите кнопку "Скачать данные"

2. Наблюдайте за прогрессом:
```text 
□ Количество полученных имен файлов

□ Количество скачанных файлов

□ Процент выполнения
```

3. Процесс автоматически завершится, когда все файлы будут скачаны

## Просмотр файлов
```
□ Все скачанные файлы отображаются в виде списка

□ Доступна пагинация (10 файлов на страницу)

□ Для каждого файла показано время скачивания (по Новосибирску)
```

## Анализ файлов
1. Выберите файлы для анализа:
```text
□ "Выбрать все на странице" - выбрать 10 файлов на текущей странице

□ "Выбрать все" - выбрать все скачанные файлы

□ "Снять выделение" - очистить выбор
```
2. Нажмите "Произвести расчёты"

3. Перейдите на вкладку "Статистика"

## Статистика
```text
□ Общая статистика - сколько раз встретилась каждая цифра во всех выбранных файлах

□ Статистика по файлам - сколько раз встретилась каждая цифра в каждом файле

□ Сумма цифр в каждом файле должна быть равна 500 (проверка целостности)
```
# 🛠 Технологии
```text

□ HTTP клиент: aiohttp (асинхронный)

□ Архивация: zipfile (встроенный)
```
